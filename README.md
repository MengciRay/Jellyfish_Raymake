# 桌面水母

《桌面水母》是一款在 Windows 桌面上慢慢养成水母的小游戏。水母会在透明窗口中游动、转向和捕食；你可以拖动它们、投喂、繁殖，观察一代代水母长出不同的颜色、伞形、触手、眼睛和背光。

每只水母都有一段 512 位的虚拟基因。子代从双亲继承基因片段，也可能发生突变，所以同一对亲代也会生出不同模样的水母。收集特殊形态可以点亮图鉴，族谱会留下已删除个体的记录。水母还会按性状定期产出金币，用于一次性的基因编辑。游戏没有死亡或限时目标，可以按照自己的节奏养护，最多同时拥有 16 只水母。

## 开始游玩

下载 [Windows 便携包](release/桌面水母-1.1.0-win.zip)，解压后运行 `桌面水母.exe`。旧版存档会自动读取；养护进度也会自动保存。

- 单击水母伞盖让它朝当前方向冲刺；双击查看个体速览；按住伞盖可拖动水母。
- 点击右上角的 `✦` 打开养护面板，或按 `Ctrl+Shift+J`。面板里可以投喂、改名、查看属性与族谱、引入野生水母，以及选择两只成熟水母繁殖。
- 在面板右上角打开图鉴或帮助。点击桌面空白处可取消选中，窗口空白区域允许鼠标穿透。
- 选中水母后可使用金币编辑它的基因；每只水母只能提交一次，每次可替换 1 到 5 个碱基。

## 从源码运行

需要 Windows 和 Node.js 24。在仓库根目录运行：

```powershell
npm.cmd install
npm.cmd run dev
```

运行 `npm.cmd test` 检查规则，`npm.cmd run smoke:electron` 检查界面流程，`npm.cmd run package:win` 生成便携包。基因细节与完整操作见 [PROJECT.md](PROJECT.md)，开发记录见 [PROGRESS.md](PROGRESS.md)。
